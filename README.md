# Veena Landing Page

This is the landing page for the Veena Mantra Songbook product, deployed via Netlify.

## Setup

This is a static HTML site. To deploy:

1. Make changes to `index.html`
2. Commit and push to GitHub
3. Netlify will automatically deploy on every push

## Deployment

The site is deployed on Netlify at [lp.veenamusic.com](https://lp.veenamusic.com)

Connected repository: `veena-landing-page` (GitHub)
